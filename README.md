# Portfolio — Simisola AGBE

Portfolio personnel de **Simisola AGBE**, étudiant en BUT Informatique à l'IUT de Reims et développeur fullstack (Symfony / React), en recherche de stage.

## Contenu

- **À propos** : profil, formation, langues
- **Compétences** : front-end, back-end & API, données & outils
- **Projets** : chatbot interne (stage Cérèsia), guide touristique rémois, application type Spotify, visualisation de données, générateur de labyrinthes
- **Parcours** : expériences et formation
- **Contact** et CV téléchargeable

## Technique

Site statique en **HTML, CSS et JavaScript natifs**, sans framework :

- design responsive (desktop, tablette, mobile) avec menu mobile accessible
- animations au défilement (IntersectionObserver) en respectant `prefers-reduced-motion`
- images optimisées (WebP) et balises SEO / Open Graph

## Lancer en local

Ouvrir `index.html` dans un navigateur, ou :

```bash
npx serve .
```
