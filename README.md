# Portfolio — Simisola AGBE

Portfolio personnel de **Simisola AGBE**, étudiant en BUT Informatique à l'IUT de Reims et développeur fullstack (Symfony / React), en recherche de stage.

## Contenu

- Haut de page : présentation et fiche (formation, stage, langues, mobilité)
- Projets : chatbot interne (stage Cérèsia), guide touristique de Reims, application d'écoute musicale, tableaux de bord de données, générateur de labyrinthes
- Compétences, parcours, contact et CV en PDF

## Technique

Site statique en HTML et CSS, sans framework ni JavaScript :

- palette volontairement restreinte (blanc craie, encre, un accent vert bouteille) avec mode sombre automatique
- police Schibsted Grotesk hébergée localement (licence SIL OFL)
- responsive, navigable au clavier, compatible `prefers-reduced-motion`

## Lancer en local

```bash
npx serve .
```
